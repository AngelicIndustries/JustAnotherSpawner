* Spawn lists are chosen by the biome at the spawn position instead of the column's, everywhere JAS looks a biome up.
* With Biomic, each sky island habitat is a biome of its own with its own spawn lists, defaulting to the spawns of the biome it hosts. Biomic's tags are attribute groups, so "A|biomic:FLOATING_ISLAND" holds every island.
* MVEL tags get wrld.biomeAt(x, y, z), wrld.biomicKeyAt(x, y, z) and wrld.biomicTagsAt(x, y, z).
* Works with EndlessIDs biome IDs.
* The biome blacklist checks the spawn position's biome instead of a wrong column.
* Biome checks by name only match where that biome is, not anywhere it exists.
* Converted max-height tags no longer stop at 256.
* Spawning events and an IS_JAS_SPAWNED tag on spawned mobs, both off by default, thanks to @cosmicdan.
* Catalogue shows JAS's logo, license and issue tracker.
* Built with the GTNH buildscript.
